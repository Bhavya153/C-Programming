# 🎓 Grade Calculator

A simple **C program** that calculates a student's grade based on the entered marks using the **ternary operator**, **switch-case**, and **conditional statements**.

---

## 📌 Features

- ✅ Accepts marks from the user.
- ✅ Assigns grades automatically.
- ✅ Displays a personalized performance message.
- ✅ Checks eligibility for the next level.
- ✅ Beginner-friendly C project.

---

## 🛠️ Technologies Used

- **Language:** C
- **Compiler:** GCC (MinGW)
- **IDE:** Visual Studio Code (Recommended)

---

## 📂 Grade Criteria

| Marks | Grade |
|-------:|:-----:|
| 90 - 100 | A |
| 70 - 89 | B |
| 50 - 69 | C |
| 33 - 49 | D |
| Below 33 | F |

---

## ▶️ How to Run

### 1. Compile the program

```bash
gcc GradeCalculator.c -o GradeCalculator
```

### 2. Run the executable

**Windows PowerShell**

```powershell
.\GradeCalculator.exe
```
