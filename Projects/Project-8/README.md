# 💻 C Programming Mini Project

## 🚀 String Length Finder & 2D Array Cube Generator

A beginner-friendly C project covering strings, built-in functions, User Defined Functions (UDF), loops, and 2D arrays.

## 📌 Programs

### 🔤 1. String Length Finder
Finds the length of a string using the built-in `strlen()` function.

**Concepts:** Strings • `fgets()` • `strlen()`

### 🔢 2. 2D Array Cube Generator
Takes rows, columns, and array elements from the user and calculates the cube of each element using a User Defined Function.

**Concepts:** 2D Arrays • `for` Loops • UDF • Functions

## 🎯 What I Learned

- Working with strings
- Using built-in functions
- Creating User Defined Functions
- Working with 2D arrays
- Using nested loops
- Taking user input
