# 📘 Basic C Programs

A collection of beginner-friendly **C programs** that demonstrate the use of **loops, arithmetic operations, character manipulation, and user input**. These programs are perfect for practicing core C programming concepts.

---

## 📌 Features

* ✅ Prints alphabets using character manipulation.
* ✅ Counts the total number of digits in a number.
* ✅ Calculates the sum of the first and last digit of a number.
* ✅ Simple and easy-to-understand code.
* ✅ Great for beginners learning C programming.

---

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC (MinGW)
* **IDE:** Visual Studio Code (Recommended)

---

## 📂 Programs Included

### 🔤 1. Alphabet Pattern

Prints alphabets in a custom sequence using a `do...while` loop and character operations.

### 🔢 2. Count Number of Digits

Accepts an integer from the user and displays the total number of digits present in it.

### ➕ 3. Sum of First and Last Digit

Reads an integer from the user and calculates the sum of its first and last digits.

---

## ▶️ How to Run

### 1. Compile the program

```bash
gcc filename.c -o program
```

Replace **`filename.c`** with the name of the program you want to compile.

### 2. Run the executable

**Windows PowerShell**

```powershell
.\program.exe
```
