# 🚀 Project 1 - Basic C Programming

This project contains three beginner-friendly C programs that demonstrate the use of variables, operators, user input, and arithmetic calculations.

## 📋 Programs Included

### 🌡️ 1. Temperature Converter
Converts temperature from **Celsius (°C)** to **Fahrenheit (°F)**.

**Formula Used:**
```
F = (9/5 × C) + 32
```

#### Example
**Input:**
```
Enter temperature in Celsius: 38
```

**Output:**
```
Temperature in Fahrenheit: 100.4
```

---

### 💰 2. Gross Salary Calculator
Calculates the **Gross Salary** using fixed allowances.

#### Fixed Percentages
- HRA = **10%**
- DA = **5%**
- TA = **8%**

**Formula:**
```
Gross Salary = Base Salary + HRA + DA + TA
```

#### Example
**Input:**
```
Enter Base Salary: 100
```

**Output:**
```
Gross Salary: Rs. 123
```

---

### 🔺 3. Triangle Angle Finder
Finds the **third angle** of a triangle when two angles are given.

**Formula:**
```
Third Angle = 180 - (First Angle + Second Angle)
```

#### Example
**Input:**
```
Enter first angle: 65
Enter second angle: 45
```

**Output:**
```
Third angle: 70
```

## ▶️ How to Run

```bash

```

### Run
```bash
./program
```

Replace `filename.c` with the name of the program you want to compile.
