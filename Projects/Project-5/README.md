- Two-Dimensional Arrays
- Matrix Operations

# 📂 Programs Included

## 1️⃣ Negative Elements in a 1D Array

### Description
Accepts an array from the user and displays all negative elements.

### Concepts Used
- 1D Arrays
- Loops
- Conditional Statements

---

## 2️⃣ Largest Element in a 2D Array

### Description
Reads a matrix from the user and finds the largest element.

### Concepts Used
- 2D Arrays
- Nested Loops
- Comparison Logic

---

## 3️⃣ Transpose of a Matrix

### Description
Accepts a matrix from the user and displays its transpose.

### Concepts Used
- Matrix Manipulation
- Nested Loops
- 2D Arrays

---

## 4️⃣ Sum of a Specific Row and Column

### Description
Allows the user to select any row and column of a matrix, then displays:

- Selected Row
- Sum of Selected Row
- Selected Column
- Sum of Selected Column

### Concepts Used

- Matrix Traversal
- Nested Loops
- User Input
- Arithmetic Operations
