# 🧮 Simple Calculator in C

> A beginner-friendly command-line calculator built using the **C Programming Language**.  
> This project demonstrates the use of **functions**, **switch-case**, **loops**, and **basic arithmetic operations**.

---

## 📌 Overview

This calculator allows users to perform basic mathematical operations through an interactive menu.

The program continues running until the user chooses to exit, making it a simple menu-driven application for learning C programming concepts.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧮 Modulus (%)
- 🔁 Menu-driven interface
- ❌ Handles division and modulo by zero
- 🚪 Exit option

## ⚙️ Operations Available

| Choice | Operation |
|--------:|-----------|
| 1 | Addition (+) |
| 2 | Subtraction (-) |
| 3 | Multiplication (*) |
| 4 | Division (/) |
| 5 | Modulus (%) |
| 0 | Exit |

---

## ▶️ How to Run

### Compile

```bash
gcc calculator.c -o calculator
```

### Execute

```bash
./calculator
```

For Windows:

```bash
calculator.exe
```
