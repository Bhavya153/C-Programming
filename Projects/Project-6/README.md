## 📚 Programs Included

| #  | Program                    | Description                                                          |

---

## 🔄 1. Palindrome String

A **palindrome** is a word or string that remains the same when reversed.

### ✨ Example

```text
Input:  madam
Output: The given string is a Palindrome.
```

```text
Input:  hello
Output: The given string is NOT a Palindrome.
```

### 🧠 Concepts Used

* Strings
* `while` loop
* `for` loop
* Conditional statements
* Character comparison

---

## 🔢 2. Character Frequency

This program counts how many times each character occurs in the given string.

### ✨ Example

```text
Input: hello

Output:
e => 1
h => 1
l => 2
o => 1
```

### 🧠 Concepts Used

* Character arrays
* Frequency arrays
* ASCII character values
* `for` loops
* Conditional statements

## ▶️ How to Run

### 1. Clone the repository

```bash

```

```bash

```

For example:


**Windows:**


